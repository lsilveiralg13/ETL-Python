## 🛠️ Tecnologias Utilizadas
- **Ferramenta de BI:** Apache Superset
- **Banco de Dados / Query Engine:** SparkSQL
- **Linguagem:** SQL

## 📥 Como Importar
1. Faça o download da pasta `yaml_exports/`.
2. Compacte a estrutura em `.zip`.
3. No seu Apache Superset, vá em **Dashboards > Importar** e selecione o arquivo.
